# Roadmap

## MVP
### Fase 1 - Estrutura e Autenticação
- [ ] Criar uma página da plataforma de caronas com as funções principais
- [ ] Criar uma página criando um resumo do projeto
- [ ] Criar uma página e sistema básico para o login e sign up

### Fase 2 - Gestão de Usuários e Menores de Idade
- [ ] Criar formulário de cadastro de perfil para estudantes
- [ ] Implementar sistema de login integrado com o SUAP
- [ ] Implementar fluxo de autenticação/autorização para responsáveis legais (para alunos menores de idade)

### Fase 3 - Publicação e Busca de Caronas
- [ ] Desenvolver interface para motoristas/passageiros cadastrarem e oferecerem caronas
- [ ] Criar sistema de busca e filtragem de caronas disponíveis para o IFMG Campus Sabará
- [ ] Implementar cálculo de distância e sugestão de divisão de custos do trajeto

### Fase 4 - Comunicação
- [ ] Implementar chat em grupo simples para os participantes da carona combinada
